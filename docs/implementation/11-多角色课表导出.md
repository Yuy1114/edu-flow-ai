# 多角色课表导出

> 更新时间：2026-09-06
> 范围：把已确认的正式课表按教师、班级、教室、教务四个视角导出为 .xlsx。
> 口径以根目录 `CONTEXT.md` 和 `docs/adr/0001`、`0002` 为准。

## 接口

```text
GET /api/exports/timetable
    ?role=TEACHER | CLASS | CLASSROOM | REGISTRAR
    &allocationTaskId=&teacherId=&classGroupId=&courseId=&classroomId=
    &weekNumber=&dayOfWeek=&status=
```

返回 xlsx 字节流，不走 `ApiResponse` 信封；文件名用 RFC 5987 的 `filename*=UTF-8''`
形式放在 `Content-Disposition` 里，中文名不会在往返中损坏。失败时仍由全局异常处理返回
JSON，前端读 blob 文本还原错误说明。

筛选维度与课表查询页完全一致，导出的就是屏幕上正在看的那一份。查询接口
`GET /api/course-assignments` 同时补上了 `allocationTaskId`，用于把一次排课发布出去的
课表单独取出来。

## 四个视角

| role | 分表方式 | 格子里省略 |
|---|---|---|
| `TEACHER` | 每位教师一张表，**主讲与助教各自成表** | 教师 |
| `CLASS` | 每个班级一张表，**合班任务的每个班都出现** | 班级 |
| `CLASSROOM` | 每间教室一张表 | 教室 |
| `REGISTRAR` | 不分表：明细 + 课时总账 | — |

每个工作簿都带一张「导出说明」：导出视角、时间、记录条数、占用原子课时、生效的筛选条件，
以及时间坐标口径。非教务视角另附「明细」平表；教务视角附「明细」与「课时总账」。

## 三条必须守住的语义

**一次授课整段占用。** 一条 `course_assignment` 占用 `consecutive_slots` 个 45 分钟原子
节次，导出把整段展开：起始节次写完整信息，后续节次写 `↳ 课程名（第3–4节 · 第1-3周）`。
只在起始格画一格等于把 4 节的实验课显示成 1 节。

**周次是显式集合，不是"整学期"。** 动态周模板下，同一个 (星期, 节次, 教室) 在第 1-6 周和
第 9-14 周可能是两门不同的课。导出把同一次课的周次压成 `第1-3周`、`第1-3,5周` 这样的区间
写进格子；同一格上的多门课并排列出，不互相覆盖。

**教师和班级的归属要用 ID 判断。** `CourseAssignmentView.teacherName` 是"主讲、助教"的合并
展示串，`classGroupName` 是合班的合并串。导出按 `primaryTeacherId` / `assistantTeacherId` /
`classGroupIds` 分表——否则助教的课会被算进主讲名下，合班的第二个班会整个丢掉。

## 规模保护

一个工作簿最多生成 60 张角色分表。超过说明筛选条件太宽（例如全校 541 位教师），接口直接
拒绝并提示先按教师、班级、教室、课程或排课任务收窄，而不是产出一个打不开的文件。

## 晚间与周末

导出表格保留完整的 11 节 × 7 天网格，晚间（9-11 节）和周末列以浅色表头标出。它们是人工
保留时段：自动排课不会使用，人工调课可以显式使用，因此必须导得出来。

## 前端入口

课表查询页（`/admin/timetable`）视图切换栏右侧有四个导出按钮，按当前筛选条件导出。下载走
`request.download`，从 `Content-Disposition` 取文件名后交给浏览器保存。

## 答辩说明

这一节要讲的不是"能导出 Excel"，而是**导出没有把领域语义丢掉**：

1. **一次授课是一段，不是一个点。** 竞品常见做法是按起始节次画一格，4 节连上的实验课在课表
   上只占 1 格。本系统按 `consecutive_slots` 整段展开，续占节次显式标记。
2. **周次是数据，不是假设。** 固定两阶段模板的系统默认"一张周课表管整个学期"。动态周模板下
   这个假设不成立，导出必须把每次课的绝对周集合写出来，并允许同一格在不同周属于不同课程。
3. **合并展示串不能当归属依据。** "主讲、助教"和合班班级名在界面上是一个串，导出必须回到
   ID 去分表，否则助教没有课表、合班的第二个班消失——这两个错误在界面上都看不出来。

演示路径建议：课表查询页 → 选一个排课任务 → 分别导出教师课表和教务总表 → 打开教师课表，
指出助教有独立 sheet、实验课占满第 5–8 节、格子里写着第 1-6 周 → 打开教务总表的「课时总账」，
指出应排/已排/差值三列。
