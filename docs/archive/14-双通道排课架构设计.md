## 核心发现

从教师跨班分布数据中发现明显的**双峰分布**：

```
教师跨班分布（624人）：

1-2班    232人 (37%)  ██████████████████
3-4班    251人 (40%)  ████████████████████
5-8班    53人  (8%)   ████
9-16班   62人  (9%)   █████
17+班    26人  (4%)   ██
```

- **低交叉教师（≤4班）**: 77%，跨班耦合可控
- **高交叉教师（≥12班）**: ~4%，公共课/核心课，全局辐射

教师跨班网络不是均匀连通的，而是存在天然的**分层结构**。这一发现决定了本文采用双通道排课策略。

## 架构设计

```
┌─────────────────────────────────────────────────────┐
│              教师跨班度统计                          │
│          ↓                     ↓                    │
│  高交叉教师 (≥12班)       低交叉教师 (<12班)         │
│    公共课 / 核心课          普通专业课 / 院系课        │
│      ≈ 4% 教师              ≈ 96% 教师              │
└────────┬──────────────────────┬─────────────────────┘
         ↓                      ↓
┌────────────────────┐  ┌─────────────────────────────┐
│ 通道 B：预排锁定   │  │ 通道 A：单班GA并行           │
│                    │  │                              │
│ · 按资源稀缺度排序  │  │ · 院系内独立GA              │
│ · 贪心/字典序插入   │  │ · 避开B通道已锁定时段        │
│ · 锁定教师-班级-时段│  │ · 并行执行，互不干扰          │
│ · 目的：零硬冲突     │  │ · 单班最优方案聚合           │
└────────┬───────────┘  └───────────┬─────────────────┘
         ↓                          ↓
┌─────────────────────────────────────────────────────┐
│              全校课表合并                            │
│          ↓                     ↓                    │
│  冲突检测（教师-时段 / 教室-时段）                    │
│          ↓                                          │
│  冲突图建模（节点=教学任务，边=冲突）                  │
│          ↓                                          │
│  连通分量分析                                       │
│    小簇（≤30任务）→ 回溯修复（深度≤2）               │
│    大簇 → 异常告警 + 特殊处理                        │
└────────────────────────┬────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────┐
│              质量优化层（ML创新）                     │
│                                                      │
│  多策略候选方案生成                                  │
│    · 教师负载优先 / 教室稀缺优先 / 公共课优先...      │
│          ↓                                          │
│  教师画像特征提取                                    │
│    · 可用性矩阵 / 偏好映射 / 时段倾向                 │
│          ↓                                          │
│  LightGBM 方案评分选优                               │
│    · 单方案 quality_score                           │
│    · 多方案对比 + 最优输出                            │
└────────────────────────┬────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────┐
│              兜底层                                  │
│                                                      │
│  人工调课 + 反馈事件采集 + LightGBM 重训练            │
└─────────────────────────────────────────────────────┘
```

## 两个通道的对比

| 对比项 | 通道 A（低交叉教师） | 通道 B（高交叉教师） |
|--------|---------------------|---------------------|
| 适用对象 | 跨班 ≤ 12 的教师 | 跨班 ≥ 12 的教师 |
| 教师占比 | ≈ 96% | ≈ 4% |
| 典型课程 | 普通专业课、院系课 | 思政、英语、体育等公共课 |
| 问题特征 | 局部耦合，冲突范围小 | 全校辐射，形成巨型冲突簇 |
| 排课顺序 | 后排 | 先排 |
| 核心策略 | 单班 GA 并行 + 合并 | 公共课预排 + 时段锁死 |
| 冲突处理 | 冲突簇修复、局部调换 | 预排阶段避免冲突 |
| 是否适合 GA | 适合 | 不适合全局 GA |
| 失败风险 | 局部失败，可修复 | 一旦失败影响大量班级 |

---

## 排课流程

1. **统计教师跨班数** — 基于真实数据计算每位教师的跨班数量
2. **高交叉教师课程预排** — 思政、英语、体育等公共课优先分配时段，锁定教师-班级-时间资源
3. **低交叉教师课程按班级 GA 并行** — GA 排课时避开已锁定时段
4. **合并全校课表**
5. **构建冲突图** — 处理剩余小规模冲突簇
6. **局部修复** — 回溯深度 ≤ 2
7. **多策略生成候选方案** — 改变排序/扰动策略
8. **教师画像 + LightGBM 对候选方案评分** — 选最优
9. **人工调课兜底** — 无法自动解决的冲突人工处理

---

## 论文定位

- **可行解生成层**：传统启发式（双通道冲突管理），不自称创新
- **质量优化层**：教师画像建模 + LightGBM 评价选优，核心创新
- **单班 GA** 作为实验对照组，证明独立排课不可直接扩展到全校级别

## 数据来源

全校真实课表数据来自 2025-2026学年第1学期，涵盖 9 个院系、499 个班级、624 位教师、4306 条教学任务。教师跨班网络的统计性质分析直接支撑了本架构的设计决策。
