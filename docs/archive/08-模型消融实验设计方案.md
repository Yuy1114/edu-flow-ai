# 模型消融实验设计方案

> ⚠️ **V3 更新 (2026-06-02)**: 本文档的 4 组消融实验设计基于 V2 的"GA + 片段评分器"框架。V3 架构下实验需重新设计：
> - 实验对象从"片段评分器对比"变为"Placement Model 对比"
> - 评估指标从"GA 方案质量"变为"placement 推荐命中率 (hit@k)"
> - 基线从"规则 + GA"变为"随机 placement + CP-SAT"
> - 画像增强组需等 V3 接入教师画像后再设计
>
> 实验方法论（统一数据、统一特征、控制变量）仍适用。详见 [17-V3-CP-SAT排课架构设计](./17-V3-CP-SAT排课架构设计.md)。
>
## 1. 实验目标

本实验不是为了证明某个模型在所有场景下绝对最优，而是为了回答以下问题：

1. 引入机器学习评分器是否比纯规则评分更有效？
2. LightGBM 相比 RandomForest、XGBoost 等模型是否更适合当前结构化排课评分任务？
3. 教师画像特征是否能提升教师偏好满足率并减少人工调整？
4. 片段级模型评分接入 GA 后，是否能改善最终完整课表质量？

核心验证口径：

```text
在相同教学任务、相同候选空间、相同 GA 搜索框架下，只替换候选片段评分方式，观察最终排课方案质量变化。
```

## 2. 实验前提

消融实验必须建立在统一数据基础上，否则对比不公平。

实验前提：

- 使用同一批学校真实课表和人工认可 AI 生成课表构造训练样本。
- 使用同一套片段级样本单位。
- 使用同一套训练 / 验证 / 测试集划分。
- 使用同一套特征 schema。
- 使用同一套 GA 参数和硬约束规则。
- 每组实验生成相同数量的候选方案。

需要固定的内容：

| 固定项 | 说明 |
|---|---|
| 教学任务 | 同一批课程、教师、班级、教室、时间片 |
| 硬约束 | 教师冲突、班级冲突、教室冲突、容量约束 |
| GA 参数 | 种群规模、迭代次数、交叉率、变异率等 |
| 数据划分 | 训练集、验证集、测试集保持一致 |
| 评估指标 | 所有组使用同一套业务指标 |

## 3. 实验组设计

建议至少设计 4 组实验。

| 组别 | 方法 | 说明 | 目的 |
|---|---|---|---|
| A | 规则 + GA | 不使用机器学习模型，只用规则 penalty 和 GA | 基线方案 |
| B | GA + RandomForest | 使用随机森林作为片段评分器 | 对比传统集成学习 |
| C | GA + LightGBM | 使用 LightGBM 作为片段评分器 | 验证主方案 |
| D | GA + LightGBM + 教师画像增强 | 在 LightGBM 特征中加入完整教师画像特征 | 验证教师画像贡献 |

如果时间充足，可以增加：

| 组别 | 方法 | 说明 |
|---|---|---|
| E | GA + XGBoost | 与 LightGBM 做 boosting 模型对比 |
| F | GA + LightGBM，无 sigmoid | 验证 sigmoid 归一化对 GA 稳定性的作用 |
| G | GA + LightGBM，无上下文特征 | 验证上下文特征对片段评分的作用 |

## 4. 各组实验说明

### 4.1 A 组：规则 + GA

A 组是基线实验，不使用机器学习模型。

评分来源：

- 硬约束冲突惩罚。
- 教室容量 / 类型匹配规则。
- 早八、晚课、连续授课等规则 penalty。
- 教师画像中的基础软惩罚。

作用：

```text
证明没有模型时，单纯规则 + GA 能达到的基础效果。
```

### 4.2 B 组：GA + RandomForest

B 组使用 RandomForest 对候选片段进行评分。

选择原因：

- RandomForest 是常见的传统集成学习模型。
- 对表格数据友好。
- 训练稳定，不容易过拟合到单棵树。
- 可作为 LightGBM 的合理对照组。

预期特点：

- 稳定性较好。
- 对复杂细粒度排序的拟合可能弱于 boosting。
- 推理成本可能高于 LightGBM。

### 4.3 C 组：GA + LightGBM

C 组是主方案，使用 LightGBM 输出候选片段质量分。

选择原因：

- 排课片段评分是典型结构化表格特征任务。
- LightGBM 对小中型表格数据友好。
- Boosting 能逐步拟合难样本，更适合学习人工调整中的细粒度偏好。
- 推理速度快，适合作为 GA 搜索过程中的局部评分器。

### 4.4 D 组：GA + LightGBM + 教师画像增强

D 组在 C 组基础上加入更完整的教师画像特征。

增强特征包括：

- 教师不可用时间。
- 教师软避让时间。
- 偏好星期 / 节次。
- 是否避免早八 / 晚课。
- 是否偏好集中排课。
- 教师最大日负载 / 周负载。
- 历史调整次数和常见调整原因。

作用：

```text
验证教师画像是否能提高教师偏好满足率，并减少人工调整次数。
```

## 5. 模型输入与输出

所有机器学习模型使用同一类片段级输入：

```text
input = teaching_task + teacher + class_group + time_slot + classroom + context
```

模型输出候选片段质量分：

```text
score_i ∈ [0, 1]
```

对于模型原始分或规则综合分，统一使用 sigmoid 归一化：

```text
raw_i = model_i - λ × penalty_i
q_i = sigmoid(raw_i / T)
```

其中 `q_i` 作为 GA 中的局部质量分。

## 6. 训练数据设置

训练数据来源：

| 数据来源 | 用途 |
|---|---|
| 学校真实课表 | 高可信正样本 |
| 人工认可 AI 课表 | 扩充正样本 |
| 人工不满意 AI 片段 | 负样本 |
| 人工调整前后片段 | 强正 / 强负样本 |
| 规则生成 sample.csv | 冷启动弱监督样本 |

数据划分建议：

```text
训练集：历史真实课表 A/B + 人工认可 AI 课表
验证集：历史真实课表 C
测试集：历史真实课表 D 或最近一次排课任务
```

注意：

- 不建议随机按片段打散划分，避免同一课表中相似片段同时出现在训练集和测试集。
- 应优先按学期、排课任务或课表来源划分。

## 7. 模型评估指标

模型指标用于判断片段评分器本身是否有效。

| 指标 | 说明 |
|---|---|
| AUC | 区分好 / 坏候选片段的能力 |
| LogLoss | 概率预测质量 |
| Precision@K | 排名前 K 个候选中正样本比例 |
| NDCG@K | 候选片段排序质量 |

如果训练数据量有限，模型指标只作为辅助，不作为最终结论唯一依据。

## 8. 排课业务评估指标

最终更重要的是业务指标，即模型接入 GA 后是否改善完整课表。

| 指标 | 说明 | 趋势 |
|---|---|---|
| 硬约束冲突数 | 教师、班级、教室冲突数量 | 越低越好 |
| 教师偏好满足率 | 满足教师画像软偏好的比例 | 越高越好 |
| 人工调整次数 | 教务需要手动修改的片段数量 | 越低越好 |
| 平均 fitness | GA 输出方案适应度 | 越优越好 |
| 方案生成耗时 | 生成一套方案所需时间 | 越低越好 |
| 方案采纳率 | 方案被人工接受的比例 | 越高越好 |
| 教室匹配率 | 容量和类型满足比例 | 越高越好 |
| 班级负载均衡度 | 班级每日课程分布是否合理 | 越均衡越好 |

## 9. 实验流程

```text
准备统一教学任务与约束
  ↓
构建训练样本
  ↓
划分训练 / 验证 / 测试集
  ↓
训练 RandomForest / LightGBM / XGBoost
  ↓
固定 GA 参数和随机种子
  ↓
分别接入不同评分器生成课表
  ↓
对每组结果做冲突检测和业务指标统计
  ↓
对比分析模型贡献
```

## 11. 预期分析方向

### 11.1 规则与模型对比

如果 B/C/D 组相比 A 组教师偏好满足率更高、人工调整次数更少，说明机器学习评分器能学习到规则之外的偏好信号。

### 11.2 RandomForest 与 LightGBM 对比

如果 C 组相比 B 组在排序指标和业务指标上更稳定，可以说明 LightGBM 更适合当前结构化排课片段评分任务。

可解释口径：

```text
RandomForest 更偏向通过多棵树平均降低方差，稳定性较好；LightGBM 属于 boosting 方法，能够逐步拟合难样本，更适合捕捉人工调整和教师偏好中的细粒度差异。
```

### 11.3 教师画像增强贡献

如果 D 组相比 C 组教师偏好满足率提高、人工调整次数下降，说明教师画像不是装饰性信息，而是有效参与了评分和优化。

### 11.4 sigmoid 归一化贡献

如果加入 sigmoid 后 GA 搜索更稳定，说明归一化有助于统一不同评分来源的尺度，避免极端分数主导搜索。

## 12. 论文表述建议

可以在论文中这样表述：

```text
为验证模型评分器和教师画像特征对排课质量的影响，本文设计了多组消融实验。在保持教学任务、硬约束、GA 参数和训练数据一致的条件下，分别比较纯规则评分、RandomForest 评分、LightGBM 评分以及加入教师画像增强特征后的 LightGBM 评分。实验从模型排序指标和排课业务指标两个层面进行评估，以验证所提出方法在候选片段质量判断和最终课表生成质量上的有效性。
```

## 13. 最小可行实验方案

如果时间有限，至少完成以下 4 组：

1. 规则 + GA。
2. GA + RandomForest。
3. GA + LightGBM。
4. GA + LightGBM + 教师画像增强。

至少记录以下 5 个指标：

1. 硬约束冲突数。
2. 教师偏好满足率。
3. 人工调整次数。
4. 平均 fitness。
5. 生成耗时。

这样就能回答老师最关心的问题：

```text
为什么选 GBM？
GBM 相比随机森林有什么效果差异？
教师画像到底有没有带来提升？
```
