## 4. 后续优先级路线

### P0：必须优先完成

1. 拿到或整理一份学校真实课表示例。
2. 定义一批固定教学任务、教师、班级、教室、时间片作为实验任务集。
3. 用 AI / 当前系统生成 5~10 套候选课表。
4. 人工筛选满意课表，形成正样本。
5. 构造片段级训练样本和基础负样本。
6. 跑最小消融实验：
   - 规则 + GA。
   - GA + RandomForest。
   - GA + LightGBM。
   - GA + LightGBM + 教师画像增强。
7. 记录核心指标：
   - 硬约束冲突数。
   - 教师偏好满足率。
   - 人工调整次数。
   - 平均 fitness。
   - 生成耗时。

### P1：实验后补充

1. 整理系统页面截图。
2. 把 Mermaid 图转成论文 / PPT 可用图片。
3. 绘制实验结果柱状图。
4. 写论文第 3、4、5 章初稿。
5. 制作 PPT 初版。

### P2：时间充足再做

1. 增加 XGBoost 对照组。
2. 增加无 sigmoid 对照组。
3. 增加无上下文特征对照组。
4. 引入 pairwise ranking 调整对样本。
5. 优化 PPT 视觉设计。

## 6. 当前不要做的事

为了避免浪费时间，暂时不建议做：

- 不要立刻写完整论文全文。
- 不要先美化 PPT。
- 不要编实验结果。
- 不要继续无限扩展理论文档。
- 不要先做复杂模型训练平台。
- 不要为了对比而堆太多模型。

当前重点应该是：

```text
把真实数据和最小实验跑通。
```

## 8. 给答辩的总口径

可以始终围绕这句话展开：

```text
本项目不是让大模型直接生成课表，而是通过教师画像提供个性化约束，使用 LightGBM 学习候选片段质量，再由 GA 完成完整课表的全局优化，并通过真实课表和人工反馈形成训练闭环。
```

如果老师继续追问，就按四条线回答：

1. GA 编码与全局优化。
2. LightGBM 选型与 RF 对比。
3. 训练样本从真实课表和人工认可 AI 课表来。
4. 消融实验验证每个模块是否真的有效。
