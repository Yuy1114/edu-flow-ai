# 真实课表导入字段模板

> 更新时间：2026-05-26
> 目标：定义学校真实课表进入训练链路前的字段格式、清洗规则和样本转换方式，为片段级训练样本构建提供统一输入。

## 1. 设计目标

学校提供的课表通常来自 Excel、教务系统导出表或人工整理表，字段命名、节次格式、周次格式、教师 / 班级 / 教室名称都可能不统一。

因此，在进入模型训练前，需要先定义一个统一导入模板，把真实课表转换成标准结构：

```text
真实课表原始文件
  ↓
字段标准化
  ↓
名称映射到系统 ID
  ↓
周次 / 星期 / 节次标准化
  ↓
课表片段样本
  ↓
训练样本构造
```

该模板只负责真实课表的输入规范，不直接负责模型训练。

## 2. 推荐原始导入字段

真实课表导入时，建议至少包含以下字段：

| 字段名 | 是否必填 | 示例 | 说明 |
|---|---|---|---|
| `source_schedule_id` | 否 | `2025-fall-cs-01` | 原始课表来源 ID |
| `semester` | 是 | `2025-2026-1` | 学期 |
| `course_name` | 是 | `高等数学` | 课程名称 |
| `course_code` | 否 | `MATH101` | 课程编号 |
| `teacher_name` | 是 | `张三` | 教师姓名 |
| `teacher_no` | 否 | `T001` | 教师工号 |
| `class_group_name` | 是 | `计科2401` | 班级或合班名称 |
| `student_count` | 否 | `45` | 学生人数 |
| `classroom_name` | 是 | `A101` | 教室名称 |
| `room_type` | 否 | `普通教室` | 教室类型 |
| `room_capacity` | 否 | `60` | 教室容量 |
| `week_range` | 是 | `1-16周` | 周次范围 |
| `day_of_week_text` | 是 | `周一` | 星期文本 |
| `period_text` | 是 | `1-2节` | 节次文本 |
| `lesson_hours` | 否 | `2` | 本次课时 |
| `remark` | 否 | `双周` | 备注 |

## 3. 标准化后的中间字段

原始课表清洗后，需要转换为系统内部统一字段：

| 标准字段 | 类型 | 示例 | 说明 |
|---|---|---|---|
| `semester` | string | `2025-2026-1` | 学期 |
| `teaching_task_key` | string | `MATH101-T001-CS2401` | 用于匹配教学任务的临时 key |
| `course_name` | string | `高等数学` | 课程名称 |
| `course_code` | string/null | `MATH101` | 课程编号 |
| `teacher_id` | number/null | `12` | 映射后的教师 ID |
| `teacher_name` | string | `张三` | 教师姓名 |
| `class_group_ids` | array | `[101]` | 映射后的班级 ID |
| `class_group_name` | string | `计科2401` | 班级名称 |
| `classroom_id` | number/null | `301` | 映射后的教室 ID |
| `classroom_name` | string | `A101` | 教室名称 |
| `week_number` | number | `1` | 第几周 |
| `day_of_week` | number | `1` | 星期一到星期日，取值 `1~7` |
| `period_index` | number | `1` | 第几大节，取值 `1~5` |
| `lesson_hours` | number | `2` | 本片段课时 |
| `data_source` | string | `real_timetable` | 数据来源 |
| `source_confidence` | number | `1.0` | 来源可信度 |

## 4. 周次转换规则

学校课表里的周次表达可能不统一，需要转换为逐周片段。

| 原始表达 | 转换结果 |
|---|---|
| `1-16周` | `1,2,3,...,16` |
| `1-8周` | `1,2,3,...,8` |
| `单周` | 只保留奇数周 |
| `双周` | 只保留偶数周 |
| `1,3,5,7周` | `1,3,5,7` |
| `第4周` | `4` |

如果一个课程在 `1-16周` 每周同一时间上课，应展开为 16 条片段样本，或先聚合成模板后再展开为片段样本。

## 5. 星期与节次转换规则

### 5.1 星期转换

| 原始文本 | 标准值 |
|---|---:|
| 周一 / 星期一 / Monday | 1 |
| 周二 / 星期二 / Tuesday | 2 |
| 周三 / 星期三 / Wednesday | 3 |
| 周四 / 星期四 / Thursday | 4 |
| 周五 / 星期五 / Friday | 5 |
| 周六 / 星期六 / Saturday | 6 |
| 周日 / 星期日 / Sunday | 7 |

### 5.2 节次转换

本项目以“大节”为基础排课单位。

| 原始节次 | 标准 `period_index` |
|---|---:|
| `1-2节` | 1 |
| `3-4节` | 2 |
| `5-6节` | 3 |
| `7-8节` | 4 |
| `9-10节` | 5 |

如果学校原始课表使用小节，需要先映射为大节。

## 6. 名称映射规则

真实课表中的教师、班级、教室名称需要映射到系统内部 ID。

### 6.1 教师映射

优先级：

```text
teacher_no 精确匹配 > teacher_name 精确匹配 > teacher_name 模糊匹配 > 人工确认
```

如果出现同名教师，必须人工确认，不能自动合并。

### 6.2 班级映射

合班课可能出现多个班级，例如：

```text
计科2401, 计科2402
```

需要拆分后分别映射到 `class_group_ids`。

### 6.3 教室映射

教室映射优先使用标准教室编号，例如：

```text
A101、教学楼A-101、A-101
```

需要统一为系统中的 `classroom_id`。

## 7. 数据质量检查

导入后需要做质量检查，避免错误数据进入训练集。

| 检查项 | 处理方式 |
|---|---|
| 教师未匹配 | 标记为待人工处理 |
| 班级未匹配 | 标记为待人工处理 |
| 教室未匹配 | 可暂时保留名称，但不进入正式训练 |
| 周次无法解析 | 标记为无效数据 |
| 节次无法解析 | 标记为无效数据 |
| 同一教师同一时间多课 | 标记冲突 |
| 同一班级同一时间多课 | 标记冲突 |
| 同一教室同一时间多课 | 标记冲突 |
| 教室容量小于学生人数 | 标记硬约束异常 |

真实课表中出现冲突时，不应直接删除，应先判断是数据录入错误、合班表达错误，还是学校实际存在的特殊安排。

## 8. 转为片段级训练样本

标准化后的真实课表可以转为片段级正样本：

```text
label = 1.0
sample_weight = 1.2
data_source = real_timetable
```

每条样本包括：

```text
teaching_task + teacher + class_group + time_slot + classroom + context
```

其中 `context` 需要基于同一张课表计算，例如教师当天负载、班级当天负载、教室当天使用情况等。

## 10. 与训练链路的关系

真实课表导入模板是模型训练数据链路的第一步。

```text
真实课表导入模板
  ↓
字段清洗与 ID 映射
  ↓
片段级样本构造
  ↓
负样本生成
  ↓
特征构造
  ↓
标签与权重
  ↓
模型训练与消融实验
```

这一步打通后，现有规则生成的 `sample.csv` 就不再是主要训练依据，而只作为冷启动和弱监督补充数据。
