# 核心图清单与草图说明

> 更新时间：2026-05-31
> 目标：提前规划论文和答辩 PPT 中必须出现的核心图，明确每张图要表达什么、放在哪一章/哪一页，以及后续需要补充的数据或截图。

## 1. 总体原则

论文和 PPT 里的图不要只是“好看”，每张图都要服务于一个答辩问题。

建议保留以下 6 类图：

1. 项目总体技术路线图。
2. 系统架构图。
3. 训练数据链路图。
4. 学习引导候选集生成 + GA 遗传搜索流程图。
5. 教师画像作用路径图。
6. 消融实验设计与结果对比图。

优先级：

| 优先级 | 图 | 用途 |
|---|---|---|
| P0 | 总体技术路线图 | 讲清项目主线 |
| P0 | 候选集生成 + GA 遗传搜索流程图 | 讲清核心算法 |
| P0 | 训练数据链路图 | 回答训练样本从哪来 |
| P1 | 教师画像作用路径图 | 强化创新点 |
| P1 | 系统架构图 | 说明工程实现 |
| P1 | 消融实验设计图 | 说明实验怎么证明有效 |
| P2 | 结果对比柱状图 | 等实验数据出来后补 |
| P2 | 系统页面截图组合图 | 等最终页面稳定后补 |

## 5. 图 4：样本单位三层结构图

### 5.1 作用

回答：为什么样本单位选片段级，而不是整张课表？

### 5.2 推荐放置位置

- 论文第 4 章：片段级样本构建。
- PPT 第 8 页：样本单位与标签设计。

### 5.3 草图

```text
方案级样本：一整张课表
  └─ 用于最终业务评估

调整对级样本：调整前片段 < 调整后片段
  └─ 用于学习人工相对偏好

片段级样本：教学任务 + 教师 + 班级 + 时间片 + 教室 + 上下文
  └─ 主训练单位，用于训练候选片段评分器
```

### 5.4 讲述重点

- 整张课表样本少、维度高，不适合作为主训练单位。
- 片段级样本数量更多、特征更清晰。
- GA 负责把片段组合成完整课表。

## 7. 图 6：候选集生成与 GA 遗传搜索流程图

### 7.1 作用

回答：模型和 GA 分别做什么？为什么不是模型直接排课？

### 7.2 推荐放置位置

- 论文第 5 章：学习引导候选集生成与遗传搜索算法设计。
- PPT 第 9~11 页：模型选型、GA 编码、评分归一化。

### 7.3 草图

```text
教学任务 + allowed时间域 + 教室资源
        ↓
Template Generator
        ↓
Room Ranker
        ↓
Placement Scorer
        ↓
Candidate Pool Builder
  每个 teaching_task 生成完整排课候选
        ↓
GA 初始化
        ↓
选择 → 交叉 → 变异
        ↓
fitness O(n) 硬约束检测
        ↓
输出 TopK 完整课表方案
```

### 7.4 讲述重点

- 模型只生成并预评分候选，不直接输出最终课表。
- 候选粒度是 teaching_task 的完整排课安排。
- GA 在 `candidate_index` 空间做完整课表组合优化。
- fitness 用硬约束、教师画像和影响因子统一评价。

## 8. 图 7：GA 染色体编码图

### 8.1 作用

回答：GA 编码到底是什么？

### 8.2 推荐放置位置

- 论文第 5 章：GA 编码设计。
- PPT 第 10 页：GA 编码与适应度函数。

### 8.3 草图

```text
Chromosome = 一张完整课表

[ TaskGene_1 ][ TaskGene_2 ][ TaskGene_3 ] ... [ TaskGene_n ]
      ↓            ↓            ↓
  教学任务1     教学任务2     教学任务3

TaskGene = {
  task_id,
  candidate_index
}

candidate_index → TaskCandidate(assignments=[...])
```

### 8.4 讲述重点

- 一个染色体是一张课表。
- 一个基因是一个教学任务的候选索引。
- 周次、时间槽和教室已经封装在 TaskCandidate 中。
- GA 不拆分单个教学任务内部课时，避免破坏课时完整性。
