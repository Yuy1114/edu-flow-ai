# GA 编码设计技术选型依据

## 一、GA 编码分类体系

遗传算法的编码设计是算法成功的关键因素之一。根据基因型（Genotype）到表现型（Phenotype）的映射方式，GA 编码可分为三个层次：

### 1.1 直接编码（Direct Encoding）

基因型与表现型一一对应，染色体上的每个基因直接映射为解空间中的一个决策变量。

| 子类型 | 典型问题 | 排课适用性 |
|---|---|---|
| 二进制编码 | 背包问题、特征选择 | ❌ 排课决策变量非 0/1 二值 |
| 排列编码 | TSP、作业调度 | ⚠️ 仅覆盖排序维度，不满足多维度联合决策需求 |
| 实数编码 | 连续函数优化 | ❌ 排课为离散决策 |

排课问题本质上是**多约束资源分配问题**，需要同时决策 时间 × 空间 × 任务 三个维度的联合分配。单一维度的经典编码无法表达完整的排课解空间。

### 1.2 间接编码（Indirect Encoding）

基因型不直接等于表现型，而是**描述了如何构造表现型**。解码器负责将基因型展开为完整方案。

```
基因型                                  表现型
template_set_id=2                  →    周次: [1, 3, 5, 7, 9, 11, 13, 15]
(选择模板集索引)                           slot: 周二第3节
                                         教室: 教301
```

GA 不直接操控底层细节，而是通过选择"构造指令"间接决定表现型。间接编码的代表性工作包括：

- **NEAT**（NeuroEvolution of Augmenting Topologies）：基因描述神经网络的结构与权重如何生长
- **Grammatical Evolution**：二进制串映射到语法规则，展开为可执行程序
- **本系统的方法**：template_set_id 索引到预生成模板集，展开为具体周次分布

**间接编码适合排课的原因**：排课问题中存在大量"枚举空间大但规律性强"的子结构（如周次分布），这类子问题可通过预枚举产生高质量候选集，GA 只需做选择题而非从头搜索。

### 1.3 混合间接编码（Hybrid Indirect Encoding）—— 本系统的定位

染色体由不同类型的基因片段组成，各自承担不同角色的决策。本系统所采用的编码可正式定位为：

> **一种混合间接编码（Hybrid Indirect Encoding）。染色体由两层决策变量构成：顶层是模板集选择变量（整数枚举型），底层是时间-空间分配变量（离散组合型）。周次分布通过预枚举模板集间接编码，时间槽与教室通过参数对直接编码。**

## 二、编码设计的理论依据

### 2.1 分解原则（Divide-and-Conquer Encoding）

排课问题天然可分解为三个子问题：

```
排课问题 = 周次分布（枚举可行解）
         + 时间段分配（组合优化）
         + 教室指派（匹配问题）
```

- **周次分布**：枚举空间大（2^16 = 65536 种），但规律性强（教师通常接受 3-5 种分布模式），适合预枚举过滤
- **时间段分配**：高维组合问题，GA 擅长此类搜索
- **教室指派**：与时间段强耦合，无法独立求解

本系统的编码将周次分布抽离为模板选择，将时间-空间联合决策保留为 GA 的主战场。这种分解显著压缩了搜索空间。

### 2.2 搜索空间压缩分析

以一个中等规模的排课场景为例：

| 维度 | 直接编码 | 本系统编码 |
|---|---|---|
| 周次分布 | 每门课 C(16, k) ∈ [11440, 12870] | 3-5 个模板集 |
| 时间段分配 | C(25, 2) = 300 | 同左 |
| 教室指派 | C(15, 2) = 105 | 同左 |
| 单任务搜索空间 | ~10^8 量级 | ~10^5 量级 |
| 50 任务总搜索空间 | 天文数字（>10^400） | 约 10^250 |

压缩的核心意义不在于让搜索空间变得"小"，而在于**使随机初始化的个体质量起点更高**——每个个体已包含合理的周次分布，无需从完全随机的周次组合开始搜索。

### 2.3 积木块假设的近似成立

经典的 Holland 模式定理（Schema Theorem）基于定长二进制串、单点交叉和位翻转变异，无法直接套用于本系统的编码结构。

但本系统的编码设计满足**积木块假设（Building Block Hypothesis）**的近似条件：

```
好的 template_set_id     +     好的 (slot, classroom)    =    好的课表片段
    低阶积木块                     低阶积木块                 组合后仍优质
```

由于交叉以任务（TaskGene）为最小交换单位，不会拆散"单个任务内部的 template_set + assignments"的搭配关系，积木块的组合性保持良好。

## 三、与其他编码方案的对比

| 对比维度 | 矩阵编码 | 事件编码 | **本系统（混合间接编码）** |
|---|---|---|---|
| 染色体结构 | 固定 5×25 矩阵 | 变长事件集合 | 变长，分层结构 |
| 搜索空间 | 巨大 | 巨大 | **中等（经压缩）** |
| 交叉破坏性 | 高（易产生无效课表） | 高 | **低（任务级语义保护）** |
| 修复复杂度 | 高（需全局重建） | 高（需全局重建） | **中（只修 slot/room）** |
| 周次表达力 | 强（全自由） | 强（全自由） | 中等（受限于模板集） |
| 收敛速度 | 慢 | 慢 | **较快** |
| 实现复杂度 | 低 | 中 | **中高** |

本系统的编码在搜索空间压缩、解质量保持、收敛速度之间取得了适合于工程落地的平衡。

## 四、编码的形式化定义

```
Chromosome = [TaskGene₁, TaskGene₂, ..., TaskGeneₙ]

TaskGene = ⟨task_id, template_set_id, [Assignment₁, ..., Assignmentₘ]⟩

Assignment = ⟨template_id, slot_id, classroom_id⟩

其中：
  - task_id ∈ ℕ              // 教学任务标识
  - template_set_id ∈ ℕ      // 模板集索引（间接编码层）
  - template_id ∈ ℕ          // 模板在模板集内的索引
  - slot_id ∈ [0, 24]        // 时间槽编码（0-4: 周一1-5节, 5-9: 周二...）
  - classroom_id ∈ ℕ         // 教室标识
```

每条染色体是 **整数 + 有序对的混合结构**，属于 GA 编码分类学中的**树型编码 / 混合编码（Tree / Mixed Encoding）**分支。
