1. 基于学习引导候选空间压缩与遗传搜索优化的高校智能排课系统设计与实现

```text
基于学习引导候选空间压缩与遗传搜索优化的高校智能排课系统设计与实现
```

理由：

- 突出学习模型对候选空间压缩的作用。

## 摘要要点

摘要后续可以围绕以下内容展开：

- 高校排课存在多约束、多目标、人工调整成本高的问题。
- 单纯规则系统难以学习教师隐性偏好，直接使用大模型生成课表又难以保证硬约束合法性。
- 本文设计一种基于学习引导候选集生成和遗传搜索优化的智能排课系统。
- 系统将教师自然语言需求结构化为画像特征，并构造片段级训练样本。
- LightGBM 用于候选排课片段质量评分，Candidate Pool Builder 生成 teaching_task 级完整候选，GA 用于完整课表全局组合搜索。
- 通过真实课表、AI 生成满意课表和人工反馈构建训练数据，并设计消融实验验证模型和教师画像的贡献。

关键词建议：

```text
智能排课；教师画像；遗传算法；LightGBM；反馈学习；消融实验
```

## 第 1 章 绪论

### 1.1 研究背景

要点：

- 高校排课涉及课程、教师、班级、教室、时间片等多类资源。
- 排课问题具有明显的组合优化特征。
- 传统人工排课工作量大，容易产生冲突，调整成本高。
- 教师偏好、课程分布、教室类型等软约束难以通过简单规则完全表达。

### 1.2 研究意义

要点：

- 降低教务人员排课和调整成本。
- 提高课表冲突检测和方案生成效率。
- 通过教师画像提升排课方案的人性化程度。
- 通过反馈训练让系统逐步学习真实排课偏好。

### 1.3 国内外研究现状

可写方向：

- 规则驱动排课方法。
- 遗传算法、模拟退火、禁忌搜索等启发式优化方法。
- 机器学习在教育管理和排课辅助中的应用。
- 大模型在自然语言偏好解析中的应用边界。

### 1.4 本文主要工作

建议写成 4 点：

1. 设计教师画像建模方法，将自然语言偏好转为结构化约束和特征。
2. 设计片段级训练样本构建链路，融合真实课表、AI 满意课表和人工反馈。
3. 设计学习引导候选集生成与遗传搜索优化方法，使用模型局部评分压缩候选空间，并由 GA 组合全校无冲突课表。
4. 设计多组消融实验，验证模型评分器和教师画像增强的实际贡献。

## 第 2 章 相关技术与理论基础

### 2.1 高校排课问题建模

要点：

- 排课问题属于多约束组合优化问题。
- 资源包括教师、班级、教室、时间片。
- 约束分为硬约束和软约束。

### 2.2 遗传算法

要点：

- 遗传算法基本流程：编码、初始化、选择、交叉、变异、适应度评价。
- 适合解决大规模组合优化问题。
- 在排课场景中可用于完整方案搜索。

### 2.3 LightGBM 模型

要点：

- LightGBM 是基于 GBDT 的高效梯度提升树模型。
- 适合结构化表格数据。
- 可用于候选片段质量评分。

### 2.4 RandomForest 与对照模型

要点：

- RandomForest 是 bagging 思路的集成模型。
- 可作为 LightGBM 的合理对照组。
- XGBoost 可作为可选扩展对照。

### 2.5 sigmoid 评分归一化

要点：

- 用于将模型分、规则惩罚分统一映射到 `[0, 1]`。
- 避免极端分数主导 GA 搜索。

对应文档：

- `docs/architecture/09-GA编码与适应度函数设计.md`
- `docs/architecture/10-LightGBM选型与模型对比说明.md`

## 第 4 章 教师画像建模与训练数据构建

### 4.1 教师画像设计

要点：

- 基础画像。
- 时间画像。
- 负载画像。
- 空间画像。
- 行为画像。

### 4.2 教师自然语言偏好结构化

要点：

- 自然语言只是输入体验。
- 结构化 JSON 才是排课事实。
- 区分硬不可排和软偏好。

### 4.3 真实课表数据采集

要点：

- 学校真实课表作为高可信正样本。
- 需要字段标准化、周次转换、节次转换、名称映射。

### 4.4 AI 生成满意课表扩充

要点：

- AI 生成课表必须经过人工筛选。
- 4~5 分方案作为正样本。
- 不满意片段作为负样本或待分析样本。

### 4.5 片段级样本构建

主样本单位：

```text
teaching_task + teacher + class_group + time_slot + classroom + context
```

### 4.6 标签与权重设计

要点：

- 真实课表片段为高可信正样本。
- 人工调整后为强正样本。
- 人工调整前为负样本。
- 规则生成 sample.csv 只作为冷启动弱监督样本。

## 第 5 章 学习引导候选集生成与遗传搜索算法设计

### 5.1 算法总体流程

流程：

```text
数据加载 → 模板生成 → 教室排序 → 片段质量评分 → 候选池构建 → GA初始化 → 进化搜索 → TopK多方案输出
```

### 5.2 GA 编码设计

要点：

- 染色体表示完整课表。
- 基因表示一个教学任务选择的候选索引。
- 每个候选是该教学任务的完整排课片段集合，包含模板、时间槽和教室。

### 5.3 约束建模

硬约束：教师、班级、教室、容量、时间范围、教师硬不可排。  
软约束：教师偏好、早晚课、连续授课、班级负载、教室匹配。

### 5.4 适应度函数设计

公式：

```text
Fitness = HardPenalty × W_h
        + SoftPenalty × W_s
        + TemplatePenalty × W_t
        - ModelQuality × W_m
```

### 5.5 LightGBM 候选片段评分

要点：

- 输入为片段级结构化特征。
- 输出 `[0, 1]` 质量分。
- 不覆盖硬约束。

### 5.6 sigmoid 归一化

公式：

```text
raw_i = model_i - λ × penalty_i
q_i = sigmoid(raw_i / T)
```

### 5.7 遗传操作与 repair

要点：

- 变异。
- 冲突修复。
