# LightGBM 选型与模型对比说明

> 更新时间：2026-05-26
> 目标：从任务特征、数据规模、模型能力、工程接入和消融实验角度说明为什么选择 LightGBM 作为候选排课片段评分器，并与 RandomForest、XGBoost、纯规则和深度学习方法进行对比。

## 1. 问题定位

本项目中的模型不直接生成完整课表，而是对候选排课片段进行局部质量评分：

```text
score(teaching_task, teacher, class_group, time_slot, classroom, context) → [0, 1]
```

也就是说，模型回答的是：

```text
某个教学任务安排到某个时间和教室，在当前课表上下文中是否合适？
```

完整课表的组合优化仍由 GA 完成。

因此，本项目的模型任务本质是一个结构化表格数据上的候选排序 / 质量评分问题，而不是文本生成、图像识别或端到端组合优化问题。

## 2. 为什么适合使用 LightGBM

### 2.1 排课评分是典型表格特征任务

候选片段评分使用的特征主要包括：

| 特征组 | 示例 |
|---|---|
| 教学任务特征 | 课程类型、总学时、学生人数、所需教室类型 |
| 教师特征 | 院系、职称、周课时上限、历史调整次数 |
| 时间特征 | 星期、节次、是否早八、是否晚课 |
| 教室特征 | 容量、类型、楼栋、容量冗余 |
| 教师画像特征 | 偏好星期、避让时间、紧凑排课偏好 |
| 上下文特征 | 教师当天负载、班级当天负载、冲突风险 |

这些特征都是结构化特征，适合树模型处理。

LightGBM 对表格数据友好，不需要像深度学习一样依赖大量样本，也不需要复杂的特征归一化流程。

### 2.2 适合小中型数据规模

毕业设计阶段能够获取的真实课表和人工反馈样本通常有限。

LightGBM 在小中型结构化数据上表现稳定，训练速度快，适合当前阶段：

- 学校真实课表数量有限。
- 人工认可 AI 课表可以补充，但仍不是大规模数据。
- 教务反馈样本需要逐步积累。
- 需要快速训练和反复实验。

### 2.3 适合学习细粒度偏好

排课中的很多偏好不是简单硬规则，例如：

- 某些教师虽然没有明确禁止早八，但历史上经常调整早八课程。
- 某些课程更适合安排在上午。
- 某些班级一天课程过密时更容易被人工调整。
- 某些教室虽然容量够，但长期不被优先选择。

LightGBM 属于 boosting 方法，可以逐步拟合前一轮难以解释的残差，更适合学习这种细粒度偏好和排序信号。

### 2.4 推理速度适合接入 GA

GA 在搜索过程中会频繁评估候选片段，因此评分器必须推理速度快。

LightGBM 模型体积相对可控，推理效率高，适合用于：

- 初始种群候选排序。
- repair 阶段候选替换排序。
- fitness 中的局部质量评分。
- 多方案生成时的重复调用。

## 3. 与 RandomForest 对比

RandomForest 是合理的对照组，但不是本项目主方案。

| 对比维度 | RandomForest | LightGBM |
|---|---|---|
| 学习方式 | Bagging，多棵树并行平均 | Boosting，逐步拟合残差 |
| 稳定性 | 稳定，不容易过拟合单棵树 | 稳定，但需控制参数 |
| 难样本拟合 | 相对较弱 | 更强 |
| 排序能力 | 可以做评分，但细粒度排序能力有限 | 更适合候选质量排序 |
| 推理效率 | 树多时推理成本较高 | 通常更高效 |
| 工程适配 | 简单 | 适合表格评分和排序任务 |

RandomForest 的优势是稳定、简单、抗噪能力强；但它主要通过多棵树平均降低方差，对人工调整这类“细粒度偏好差异”的拟合能力通常不如 boosting。

因此，本项目把 RandomForest 作为消融实验对照组，而把 LightGBM 作为主评分器。

## 4. 与 XGBoost 对比

XGBoost 和 LightGBM 都属于 boosting 系列，都是可选方案。

| 对比维度 | XGBoost | LightGBM |
|---|---|---|
| 模型类型 | Boosting | Boosting |
| 表格数据表现 | 强 | 强 |
| 训练速度 | 较快 | 通常更快 |
| 大特征 / 大样本效率 | 较好 | 更适合高效训练 |
| 工程复杂度 | 中 | 中 |
| 当前项目定位 | 可作为增强对照 | 主方案 |

如果时间充足，可以在消融实验中加入 XGBoost；如果时间有限，优先比较规则、RandomForest 和 LightGBM 即可。

论文中不需要绝对否定 XGBoost，可以表述为：

```text
XGBoost 与 LightGBM 均适合结构化数据建模。考虑到本项目需要在排课搜索过程中频繁调用评分器，并希望保持较高训练与推理效率，因此优先选择 LightGBM 作为主模型，同时可在消融实验中将 XGBoost 作为扩展对照。
```

## 5. 与纯规则评分对比

纯规则评分可解释性强，是排课系统必须保留的基础能力。

纯规则适合处理：

- 教师冲突。
- 班级冲突。
- 教室冲突。
- 容量约束。
- 教师明确不可排。

但纯规则不足在于：

- 难以学习真实课表中的隐性偏好。
- 难以从人工调整行为中持续改进。
- 权重依赖人工经验，调参成本高。
- 对“合法但不优”的候选区分能力有限。

因此，本项目不是用 LightGBM 替代规则，而是采用：

```text
规则保证合法性，LightGBM 学习软偏好和局部质量排序。
```

## 6. 与深度学习方法对比

深度学习方法不作为当前阶段主方案，原因包括：

- 真实课表和人工反馈数据量有限。
- 排课片段特征主要是结构化表格特征，不是深度学习最有优势的图像或文本任务。
- 模型解释成本较高，不利于论文答辩和教务业务解释。
- 训练和调参成本更高，不适合当前毕业设计阶段。
- 端到端生成课表容易违反硬约束，仍需要规则和修复机制兜底。

可以把深度学习作为未来扩展方向，而不是当前主路线。

## 7. LightGBM 在系统中的边界

LightGBM 只做局部评分，不做硬约束决策。

它不负责：

- 判断教师 / 班级 / 教室硬冲突是否合法。
- 决定教学任务是否完整排完。
- 直接生成一整张课表。
- 覆盖教师硬不可排约束。

它负责：

- 给候选片段一个质量分。
- 学习真实课表和人工反馈中的偏好模式。
- 帮助 GA 更快找到高质量组合。
- 支持不同模型评分器的消融实验。

## 8. 消融实验设计

为了证明 LightGBM 的选择不是主观判断，需要进行消融实验。

建议实验组：

| 组别 | 方法 | 目的 |
|---|---|---|
| A | 规则 + GA | 基线 |
| B | GA + RandomForest | 对比传统集成学习 |
| C | GA + LightGBM | 验证主模型 |
| D | GA + LightGBM + 教师画像增强 | 验证教师画像贡献 |
| E | GA + XGBoost | 可选扩展对比 |

评估指标：

| 指标 | 说明 |
|---|---|
| AUC / NDCG@K | 模型候选排序质量 |
| 硬约束冲突数 | 最终课表合法性 |
| 教师偏好满足率 | 教师画像是否被满足 |
| 人工调整次数 | 教务后处理成本 |
| 平均 fitness | GA 输出方案质量 |
| 生成耗时 | 工程效率 |
| 方案采纳率 | 最终业务可用性 |

## 9. 论文表述建议

可以在论文中这样写：

```text
本研究选择 LightGBM 作为候选排课片段评分模型，主要原因在于排课片段评分任务具有典型的结构化表格特征形式，且当前阶段真实课表和人工反馈样本规模有限。相比深度学习方法，LightGBM 对小中型表格数据更友好，训练和推理效率更高，解释成本更低；相比 RandomForest，LightGBM 采用 boosting 思路，能够逐步拟合难样本，更适合学习人工调整和教师画像中体现的细粒度偏好。需要强调的是，LightGBM 并不替代遗传算法和硬约束规则，而是作为局部评分器，为 GA 的全局搜索提供数据驱动的候选质量信号。
```

## 10. 答辩回答口径

如果老师问“为什么选 GBM，不选随机森林”，可以回答：

```text
因为本项目的模型任务不是直接生成课表，而是对候选排课片段进行结构化评分。RandomForest 比较稳定，适合作为对照组，但它主要通过 bagging 平均多棵树来降低方差；LightGBM 属于 boosting 方法，能逐步拟合难样本，更适合学习教务调整和教师画像中的细粒度偏好。因此我会把 RandomForest 放进消融实验中对比，而主方案选择 LightGBM。
```

如果老师问“为什么不用深度学习”，可以回答：

```text
当前数据主要是结构化表格特征，真实课表和人工反馈样本量也有限。深度学习需要更多数据，解释成本更高，而且端到端生成课表容易违反硬约束。因此本项目更适合采用规则保证合法性、LightGBM 学习局部偏好、GA 做全局优化的组合方案。
```

如果老师问“LightGBM 起什么作用”，可以回答：

```text
LightGBM 不直接排课，也不覆盖硬约束。它只对候选片段输出 0 到 1 的质量分，这个分数进入 GA 的初始化、候选排序、repair 和适应度函数，帮助 GA 在合法候选空间中更快找到质量更高的完整课表。
```
