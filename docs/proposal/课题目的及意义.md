# 课题目的及意义（含国内外研究现状分析）

## 一、选题背景与研究目的

### 1. 选题背景

高校排课需要协调课程、教师、班级、教室及授课时间等多类资源，同时满足时间互斥、教室容量与类型匹配、连续授课和有效周次等约束。随着合班教学、实验实训和差异化授课安排的增加，排课问题呈现出较强的组合复杂性。传统人工编排需要反复核对资源占用和教学任务完成情况，调整一项安排还可能影响其他课程，增加教务人员的核查与协调工作量。

实际教学数据也存在非标准表格、资源名称不一致、授课周次不规则及声明课时与实际安排不一致等情况。因此，排课系统除了提供求解算法，还需要建立数据清洗、约束校验、人工复核和发布管理机制，使计算结果能够进入实际教务业务流程。

### 2. 研究目的

本课题拟基于 Spring Boot、React 与 Python 构建高校智能排课 Web 系统，以教学任务为基本排课单位，形成基础数据管理、自动排课、人工微调、审核发布及导出打印的业务闭环。具体研究目的如下：

1. **建立符合实际教学业务的约束模型。** 在绝对周次和原子小节坐标上描述教学活动，支持多教师、多班级和连续授课，明确教师、班级与教室时间互斥、容量、房型、禁排及有效周次等硬约束，并独立审计教学任务覆盖情况和课时完成情况。
2. **设计约束驱动的启发式排课方法。** 通过资源必要容量预检、任务优先级排序、合法候选枚举、贪心放置及有界局部重排生成候选课表；按照各周实际安排派生动态周模板，允许课程结束后释放后续周次资源。
3. **实现软约束权重调整与多次求解。** 在硬约束合法的前提下，使用可配置的软约束评分引导候选选择，并通过不同任务排序或候选选择策略生成方案，比较排课完成情况、软约束满足程度和计算耗时。
4. **实现可审计的人机协同流程。** 提供周历课表和教师、班级、教室等查询维度，支持按精确周次进行人工微调。修改后重新检查约束和课时，拒绝违反硬约束的操作，并记录人工复核与发布结果。
5. **验证任务书规定的性能与正确性指标。** 使用实际教学数据构建100门课程、50间教室的典型规模算例，以排课计算时间不超过30秒为验收目标；通过标注样本与冲突注入实验，验证规定硬约束范围内的冲突检出率达到100%。上述指标作为待验证目标，不预先视为已达到的实验结论。

## 二、国内外研究现状分析

### 1. 国外研究现状

国外高校排课研究形成了多种求解路线，包括整数规划、约束求解、局部搜索及混合方法，不同路线在求解质量、运行时间和约束表达能力方面各有特点。ITC 2019相关研究同时讨论了混合约束元启发式求解器和混合整数规划方法，说明精确方法与启发式方法仍在并行发展，不能将该领域概括为“已全面转向混合遗传算法”。[1]

国外研究也重视真实实例与统一评测。ITC 2019基于实际高校数据建立算例，涉及时间与教室分配、学生分班、不同授课周次及多种硬软约束，并提供结果校验机制。这表明，排课研究需要同时考虑模型对实际业务的表达能力、方案合法性和给定时间预算内的求解表现。[1]

对本课题而言，相关研究的主要启示是：使用明确的硬软约束模型，在实际数据上评价算法，并完整报告测试规模、约束条件、排课完成情况和运行时间。其他研究的性能结果不能直接作为本项目满足30秒指标的依据。

### 2. 国内研究现状

国内相关研究与技术方案也呈现出多种路线。例如，《基于改进GWO算法的高校教学管理系统排课算法研究》通过改进种群初始化与搜索过程处理排课问题；《面向统一教学资源的人机协同启发式排课系统》则提出将约束转化为启发式规则，并结合自动排课与人工安排。[2][3] 这些实例体现了智能优化、规则处理和人机协同等不同探索方向，但不能据此认定某一种算法或技术架构已成为国内统一主流。

在本课题所面向的学校场景中，行政班与合班关系、连续实验课、专用教室和有效周次是需要重点表达的业务条件。借鉴已有方法时，应核对其任务粒度、时间语义和资源假设，避免直接套用简化算例而遗漏实际约束。

Spring Boot与React符合本课题的系统建设要求，Python则用于排课计算与数据处理。三者协同是本项目依据业务职责作出的工程选择，其适用性将通过接口联调、持久作业和业务闭环验证，而不预设为行业通用结论。

### 3. 本课题的研究定位

本课题以实际教学任务和课表数据为基础，选择任务书允许的启发式规则路线，重点研究多周资源占用、动态周模板、约束权重调节及人工复核机制，并将算法结果与发布、查询和导出流程衔接。

研究评价将同时关注任务覆盖率、课时偏差、硬冲突、软约束评分及运行时间。对于无法自动完成的任务，保留具体原因并提供人工处理入口，避免以不完整课表或静默放宽约束的方式满足时间指标。

## 三、研究意义

### 1. 算法与建模意义

本课题探索将多教师、多班级、有效周次和连续授课统一到原子时间坐标中的建模方式，并通过合法候选枚举与有界局部重排处理资源冲突。结合动态周模板与课时守恒审计，评价启发式规则在特定实际教学规模下的可行性、效率和解释能力，为同类资源调度系统提供可复现的实现与实验参考。

### 2. 教务应用意义

系统通过批量数据处理、自动排课和冲突检测，减少重复录入与人工核对工作；通过精确周次微调、未排原因展示和审核发布，帮助教务人员识别调整影响并保留处理记录。资源配置和人工调整效率的改善程度，将通过软约束指标及实际使用验证评价，不预先宣称已显著提高资源利用率。

### 3. 工程实践意义

课题将需求分析、数据治理、算法设计和前后端开发结合起来，实践Java业务服务、Python计算服务与React前端之间的契约设计和协同运行。通过作业状态持久化、修改后重审计和事务发布，形成从输入数据到正式课表的可追溯流程，并以实际数据实验和功能验收检验系统效果。
