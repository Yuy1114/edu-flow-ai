# 课题预期结论或过程中的特色、创新点

## 一、课题预期结论与成果

### 1. 启发式排课方法的适用性验证

预期通过实际教学数据实验，评价约束驱动的启发式规则在合班、多教师、多周和连续授课场景中的适用性。以100门课程、50间教室典型规模下计算时间≤30秒为验收目标，同时检查任务覆盖率、未排课时、硬冲突及课时偏差。

对于可完成的验收算例，目标是生成完整且无硬冲突的方案；对于资源不足或搜索预算内未完成的实例，输出可解释的未排原因。最终结论以实验结果为依据，不预先宣称算法能够保证所有实例均可排。

### 2. 冲突检测能力验证

预期通过标注样本及冲突注入实验，证明检测器在规定硬约束测试范围内的检出率达到100%，并报告合法样本的误报情况。明确检测范围及边界，不以数据结构或单项测试直接推导“全域零遗漏”。

### 3. 系统业务闭环验证

交付基于Spring Boot、Python/FastAPI、React与MySQL的Web系统，完成基础数据批量导入导出、自动排课、权重调整、多次求解、课表人工微调、复核发布和导出打印。通过端到端测试检验后台作业、状态查询、编辑重审计及事务发布的一致性。

### 4. 工程与论文材料

提供源代码、约束及算法设计说明、数据库设计与迁移文件、接口和部署文档、功能测试及性能实验报告。毕业论文依据可复现证据总结效果、适用条件和局限。

## 二、拟探索的特色与创新点

以下内容作为本课题拟探索的特色方向。是否构成学术创新及其效果，应结合文献比较、实现细节和实验结果判断，不以采用常见算法、数据结构或框架本身作为创新结论。

### 1. 面向多周合班教学任务的统一建模

将一项教学任务的全部教师、班级、有效周次和连续占用跨度纳入统一模型，在原子小节上检查资源互斥。结合逐任务与全局课时审计，避免单班拆分、周次简化和仅检查起始槽位带来的遗漏。

### 2. 资源完成即释放与动态周模板生成

先按绝对周次求解，课程完成后释放后续周资源，再将安排相同的周压缩为动态模板。研究该机制对不同持续周数任务的资源复用和结果表达的作用，并通过对比算例评价其效果，不预设模板越少或复用越多就一定更优。

### 3. 硬可行域内的软约束调节与有界局部重排

在不放宽硬约束的前提下，通过可配置评分引导合法候选选择，并对贪心放置失败的任务执行有界局部重排。结合不同求解策略比较覆盖率、偏好满足程度和时间开销，研究搜索预算与排课质量之间的关系。

### 4. 带课时审计的人机协同复核与发布

对未排任务和课时偏差提供明确原因，支持按单周或非连续周进行人工修改，每次修改后重新审计。硬约束问题不可豁免；其他复核事项记录处理原因，并在草案变化后重新判断接受记录的有效性。通过事务发布将复核结果与正式课表衔接。

### 5. 可追溯的跨语言作业与验证流程

明确Java业务服务、Python计算服务与React交互层的职责，通过持久作业记录、配置快照、导入批次和实验产物追踪输入与结果。该架构作为工程实践特色，其价值通过状态恢复、异常处理和端到端验证体现，不将跨语言组合本身视为算法创新。
