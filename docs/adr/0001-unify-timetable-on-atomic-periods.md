# 统一使用 11 个 45 分钟原子小节

学校每日教学时间由上午 4 节、下午 4 节、晚上 3 节组成。系统统一以 45 分钟原子小节作为 `period_index` 的单位：完整时间轴为 1–11，自动排课默认只搜索周一至周五的 1–8，9–11 与周末作为人工保留时段。普通理论课一次连续占 2 小节，实验或上机课一次连续占 4 小节；人工操作仍可显式使用完整 1–11 时间轴。

## 修订（2026-09-06）：晚间从 2 节改为 3 节

本 ADR 最初写作 10 节（晚上 9–10）。真实课表表尾的作息说明写明：

```text
上午1-2节：8:15-9:50      上午3-4节：10:05-11:40
下午5-6节：14:30-16:05    下午7-8节：16:20-17:55
晚上9-11节：19:10-21:35
```

晚间是一个 145 分钟的三节大块，10 节的坐标装不下第 11 节，真实晚间课程会无处安放。
迁移 `014_extend_evening_to_period_11.sql` 只新增第 11 节坐标，不改动既有行，
因此 `time_slot.id` 与 `course_assignment.time_slot_id` 等外键引用全部保持不变；
标准坐标数从 18×7×10=1260 变为 18×7×11=1386。自动排课域仍是工作日 1–8，未受影响。

## Consequences

- 数据库、Java、Python、前端、教师画像和后续训练样本必须使用同一 `period_index` 坐标。
- “占用小节数”与“每次计入课时数”语义分离，但在当前学校规则下均以 45 分钟为一个单位。
- 自动排课候选域与完整人工可编辑域是两个集合，不能通过删除晚间或周末时间槽来表达自动禁排。
