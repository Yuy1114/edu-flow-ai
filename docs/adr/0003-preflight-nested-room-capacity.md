# 在排课前执行教室分层必要容量预检

只比较“教室总课时”会隐藏容量层级瓶颈。例如，大量双班课只能使用大教室；即使小教室空闲，也无法接手这些任务。

在进入搜索前，系统对每个房型和每个教室座位分界执行嵌套容量检查：学生数不低于该分界的任务总课时，不得超过能容纳该分界的教室在自动排课域内的总课时。固定或候选教室任务还要求其绑定池内至少有一间房型、容量合法的教室。

## Consequences

- 预检失败可以证明当前自动域的教室容量必然不足，应在页面和产物中显式展示缺口。
- 预检通过只是必要条件，不是可排证明；教师、班级、禁排、连续节次等联合约束仍由实际排课和终审判定。
- 均衡模拟数据必须先通过该预检，才可用于验收搜索算法；资源压力场景可以有意失败，但必须进入显式人工复核状态。
